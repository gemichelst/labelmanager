Label Settings

Go to Settings → Label Profile. These values appear in generated PDFs, royalty statements, EPKs and emails.

FieldDescription
Label NameYour trading name, appears on all exports
LogoPNG/SVG, used in PDFs and portals (recommended: 400×400)
Default CurrencyEUR / USD / GBP — used across Finance and Royalties
VAT / Tax NumberPrinted on royalty statements and invoices
Bank / IBANShown on statements (stored in localStorage, never transmitted)
Statement FooterLegal text appended to all PDF statements
TimezoneUsed for deadline calculation and calendar display

User Management

Navigate to Settings → Users & Roles. The admin can create, edit and deactivate accounts.

Default demo accounts

EmailPasswordRole
admin@label.comadmin1234Admin

⚠️
Change passwords before going live.

Passwords are stored in localStorage as plain strings in this client-side build. For production, replace with a real backend auth system.

Notifications & Webhooks

The 🔔 bell in the topbar shows live in-app notifications. Configure Slack/Discord webhooks under Integrations → Webhooks.

Webhook trigger events

Event keyTriggers when…
demo.submittedNew demo arrives via public upload form
demo.signedA demo reaches the Signed pipeline stage
release.createdA new release is added
release.status_changedRelease changes any status
gig.confirmedA booking moves to Confirmed
contract.expiringContract expires within the warning window
task.overdueA task passes its due date incomplete

Integrations

Demo platform import (CSV)

Under Integrations → Platform Import, drop a CSV from LabelRadar, SubmitHub, or Soundplate to bulk-import demos. The importer deduplicates by submitter email + track title.

Distributor export

Select any release and click Export for Distributor. Supported formats: DistroKid CSV, FUGA XML, Believe/Orchard TSV, Bandcamp JSON.

Import & Export

Use Settings → Export → Export All Data to download a full ZIP archive (JSON + CSV + media manifest) covering all artists, contacts, demos, releases, finance entries, royalty statements and activity logs.

Bulk CSV import is available for: artists, contacts, demos, releases. Download the template first to match column names.

Backup & Safety

✅
All data is stored in your browser's localStorage

Nothing is sent to any server in this client-side build. Export your data weekly as a safety backup.

Danger Zone

🔴
These actions are permanent.

All Danger Zone actions require Admin role and a confirmation dialog where you must type the label name.

ActionEffect
Delete ArtistRemoves artist + all linked demos, releases and contracts
Wipe Rejected DemosPurges all demos with Rejected status older than X days
Reset All DataClears localStorage entirely — only available in dev mode
Transfer OwnershipAssigns Admin role to another user, downgrades yours to Label Manager
