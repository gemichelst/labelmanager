Set your label's global identity. These values appear in generated PDFs, statements, EPKs and emails.

User Management

Go to Settings → Users to invite, edit or deactivate team members.

Inviting a new user

  1. Click + Invite User
  2. Enter name, email address and select a role
  3. The user receives an email with a one-time sign-in link valid for 48 hours
  4. On first login they set their own password

Deactivating a user

Deactivated accounts can no longer log in but all their history, comments and task assignments are preserved. Deactivation is reversible — click Reactivate at any time.

⚠️
You cannot deactivate your own account.

Ask another Admin to deactivate you, or transfer ownership first.

Notifications

Configure when and how LabelManager OS alerts you. Go to Settings → Notifications.

In-app notifications

The 🔔 bell in the top-right shows an activity feed. The following events always generate an in-app notification:

  • New demo submitted (for Admin, Label Manager, A&R roles)
  • Demo status changed to Signed or Rejected
  • Release date changed
  • Task overdue (assigned user + Admin)
  • Contract expiry within 30 days
  • Royalty statement generated for an artist

Email notifications

Email digests can be set to Immediate, Daily summary or Off per event category. Configure per-user under Settings → Notifications → Email Preferences.

Slack / Discord webhooks

Send real-time alerts to a Slack channel or Discord server. Configure under Settings → Integrations → Webhooks. Supported trigger events:

Event keyTriggers when…
demo.submittedA new demo arrives via the public form
demo.status_changedA demo moves to any new pipeline stage
demo.signedA demo reaches the Signed stage
release.createdA new release is added
release.status_changedA release changes status
gig.confirmedA booking reaches Confirmed status
task.overdueA task passes its due date without completion
contract.expiringA contract expires within the configured warning window

Integrations

Navigate to Settings → Integrations to connect LabelManager OS to external services.

Demo Platform Import

Drop a CSV from LabelRadar, SubmitHub, or Soundplate to bulk-import demos into your A&R pipeline. The importer maps columns to LabelManager fields and deduplicates by submitter email + track title.

Distributor Export

Select a Release and click Export for Distributor. Choose a template:

  • DistroKid CSV — track-level upload sheet
  • FUGA XML — full DDEX-lite package
  • Believe / The Orchard CSV — metadata sheet + asset manifest
  • Bandcamp — album CSV with track listing

Royalty Statement Delivery

When a statement is generated, it can be automatically emailed to the artist using a configured SMTP account (Settings → Email → SMTP Config) or delivered via the Artist Portal.

Import & Export

Bulk import (CSV)

Import artists, contacts, demos or releases in bulk via CSV. Go to Settings → Import → select entity type → upload CSV. Download the template first to ensure column names match.

Full data export

Export your entire label dataset as a structured ZIP archive (JSON + CSV + media manifest). Go to Settings → Export → Export All Data. The export includes:

  • All artists, contacts, demos, releases, tracks, events, finance entries
  • Royalty statements (PDF + JSON)
  • Media file manifest (URLs or base64 depending on storage mode)
  • All user activity logs

Backup & Data Safety

✅
PostgreSQL automatic backups (production)

When deployed via Railway or Supabase, daily automated backups are managed by the hosting provider. Configure retention period (7–30 days) in your hosting dashboard.

For the single-file demo version (localStorage), use Settings → Export → Export All Data weekly as your manual backup. Store the ZIP in Google Drive, Dropbox or an S3 bucket.

Danger Zone

⚠️
These actions are irreversible.

All Danger Zone actions require Admin role and a confirmation dialog where you must type the label name to proceed.

ActionWhat it does
Delete ArtistRemoves artist + all linked demos, releases, contracts. Royalty statements are archived.
Wipe Demo PipelineDeletes all demos with status Rejected that are older than a configurable date.
Reset All DataWipes the entire database. Only available in development mode.
Transfer OwnershipAssigns the Admin role to a different user and downgrades your own role to Label Manager.
