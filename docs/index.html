LabelManager OS - User Manual

Welcome to the official documentation for LabelManager OS. This system is a single-page application designed to manage the entire lifecycle of an independent record label.

Core Concepts

  • Single Source of Truth: Everything revolves around your Artists and Releases. When you create a Release, it links to Artists, Contracts, Media, and Royalties automatically.
  • Local-First: The app runs entirely in your browser using localStorage. No backend is required, but you can export/import your database as a JSON file at any time.
  • Role-Based Access: The UI adapts depending on who logs in (Admin, A&R, Label Manager, Artist).

Getting Started

Simply open the index.html file in your browser. To ensure file uploads and the Waveform player work perfectly without CORS issues, serve the directory locally:

python3 -m http.server 8080
