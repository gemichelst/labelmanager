What is LabelManager OS?

LabelManager OS is a single-page web app (no backend, no server required) that runs entirely in the browser. All data is persisted in localStorage, making it instantly deployable on GitHub Pages, Netlify, or any static host.

Core Concepts

ConceptDescription
localStorage DBAll data lives in LOS.db, auto-saved to localStorage on every change. No server needed.
Role (RBAC)Every user has one of four roles: Admin, Label Manager, A&R, Artist. Roles control which modules and actions are visible.
ViewsEach module is a "view" — rendered on demand by LOS.renderAll(). Navigation switches views without page reload.
Public Uploadupload.html is a standalone public demo submission form. No login required.
DocsThis manual lives in docs/ and opens inline via the ❓ help button in the app.

System Requirements

  • Any modern browser: Chrome 110+, Firefox 115+, Safari 16+, Edge 110+
  • JavaScript enabled
  • ~5 MB localStorage quota (default browser quota is 5–10 MB)
  • Internet connection only needed for Google Fonts + Lucide icons CDN on first load
💡
Offline use

After the first load, the service worker caches all assets. The app works fully offline thereafter.
