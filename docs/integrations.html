🔌 Integrations

Connect LabelManager OS to your external tools — Slack, Discord, Make, demo platforms, and distributors — to keep your whole workflow in sync.

Outgoing Webhooks

Webhooks send an HTTP POST with a JSON payload to any URL when specific events occur in the app. Use them to connect to Slack, Discord, Make.com, Zapier or any custom endpoint.

Creating a Webhook

1
Go to Integrations → Webhooks → + New Webhook
2
Paste your webhook URL

For Slack: create an Incoming Webhook at api.slack.com/apps. For Discord: right-click a channel → Edit Channel → Integrations → Webhooks.

3
Select trigger events
  • demo.new — new demo submitted
  • demo.status_changed — demo moved to any stage
  • release.created — new release record added
  • gig.confirmed — booking reaches Confirmed stage
  • payout.created — artist payout recorded
  • contract.expiring — contract within 30 days of expiry
4
Test it

Use the Test Webhook panel to send a sample payload for any event type. The JSON preview shows exactly what will be sent.

Sample Webhook Payload

{
  "event": "demo.new",
  "timestamp": "2026-05-08T03:00:00Z",
  "data": {
    "id": "d_abc123",
    "title": "Acid Rain",
    "submitter_name": "DJ Void",
    "submitter_email": "djvoid@example.com",
    "genre": "Techno",
    "bpm": 138,
    "status": "new",
    "submitted_at": "2026-05-08T02:58:00Z"
  }
}

Platform Import (Demo Platforms)

Import demo submissions from external platforms directly into your A&R Kanban.

PlatformExport formatImport steps
LabelRadarCSVReports → Export CSV → drop in LabelManager Import
SubmitHubCSVDashboard → Export → CSV → import as "SubmitHub"
SoundplateCSVSubmissions → Export → import as "Soundplate"
DropTrackCSVMy Submissions → Export → import as "DropTrack"
GenericCSVAny CSV with columns: title, artist, email, genre, url

After import, all demos land in the New column of your A&R Kanban with the platform name tagged as the submission source.

Distributor Export

Generate a distribution-ready metadata package for any release:

  1. Go to Integrations → Distributor Export
  2. Select the distributor from the dropdown
  3. Select the release
  4. Toggle which fields to include (ISRC, credits, splits, territory restrictions)
  5. Click Generate Export — preview appears on the right
  6. Click Download to save the file

Integration Logs

Every integration action (import, export, webhook delivery) is logged in Integrations → Logs. Each log entry shows:

  • Timestamp
  • Action type (import / export / webhook)
  • Target (platform name, distributor, webhook URL)
  • Status (success / failed / partial)
  • Record count (how many demos/releases processed)

Failed webhook deliveries show the HTTP status code and response body for debugging. Use Retry to re-send a failed webhook.
