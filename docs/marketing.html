📣 Marketing & Smart Links

Create Smart Links, pre-save campaigns, timed promo pools and press kits — all without leaving LabelManager OS.

Smart Links

A Smart Link is a single URL that redirects listeners to the right DSP based on their location and device. Create one per release.

Creating a Smart Link

1
Go to Marketing → Smart Links → + New Smart Link
2
Link it to a Release

The release title, artist name and artwork are pulled automatically.

3
Add DSP URLs

Paste the streaming URL for each platform: Spotify, Apple Music, Beatport, Bandcamp, SoundCloud, YouTube, Tidal, Amazon Music, Deezer, Juno.

4
Enable Pre-Save (optional)

If the release isn't out yet, enable pre-save mode. The link captures fan email addresses and triggers a notification to each fan when the release goes live.

5
Copy the link and share

The Smart Link URL format: yourdomain.com/r/SLUG. In the single-file version, the link renders as an internal preview page.

Promo Pool

The Promo Pool lets you share tracks with DJs, blogs and radio programmers before release — with time-limited access and optional password protection.

  • Create a Promo Link — link to a media asset, set expiry date (e.g. 14 days before release)
  • Password protect — optional password for sensitive promos
  • Track plays — see who played what, how many times, from which geography
  • Download limit — set max downloads per link (e.g. DJ copy: 1 download)
  • Batch promo — generate personalised promo links for a contact list (one per DJ/blog)

EPK Generator

Generate a live Electronic Press Kit (EPK) for any artist directly from their profile data. The EPK is a self-contained HTML page including:

  • Artist bio and photo
  • Latest releases with embedded player
  • Key stats (monthly listeners, followers — if entered manually)
  • Upcoming events
  • Social links and booking contact
  • Press quote section

Go to Artists → [Artist Name] → ⋯ → Generate EPK. The EPK downloads as a single HTML file that can be hosted anywhere or sent as an email attachment.
