📁 Media Library

The Media Library is the central asset store for all label files — audio masters, artwork, press photos, stems, social assets, videos, documents. Everything is tagged, versioned and searchable.

Uploading Assets

1
Click + Upload or drag files onto the library grid

Supports batch upload of up to 20 files at once. Accepted formats: audio (MP3, WAV, AIFF, FLAC, M4A), images (JPG, PNG, TIFF, WebP), video (MP4, MOV), documents (PDF, DOCX).

2
Fill in metadata for each file

The metadata panel opens automatically after upload. At minimum, set the Type, Artist and Version fields — the rest can be filled in later.

3
Link to a Release (optional)

Linking an asset to a release makes it appear in the Release's Assets tab and in the Distributor Export packager.

Asset Metadata Fields

FieldDescription
TitleHuman-readable name for the file
TypeMaster, Radio Edit, Extended, Stems, Instrumental, Artwork, Press Photo, Logo, Social Asset, Video, Document
VersionStreaming Master, Club Master, Vinyl Master, DJ Copy, etc.
ArtistLinked artist from roster
ReleaseLinked release record
TerritoryTerritory restrictions for this version
TagsCustom free-text tags for search
Approved For Artist PortalWhether this file appears in the artist's portal
NotesInternal notes (e.g. "Do not share — stems for label use only")

Waveform Player

All audio files render with an interactive WaveSurfer.js waveform. Features:

  • Click to seek — click anywhere on the waveform
  • Zoom — scrollwheel over the waveform to zoom in/out
  • Markers — right-click to add labelled markers (Intro, Drop, Break, Outro)
  • Loop region — drag a selection to set a loop region, then enable loop mode
  • Volume & speed — controls below the waveform

Multiple audio files can be queued — the queue panel appears on the right. Playback continues between files.

Versions & File Management

The Version field groups related files. For example, a track may have versions: Streaming Master, Club Master, Vinyl Master, Radio Edit and Instrumental. The library groups these under the track title when grouped by Release in the view settings.

To replace a file (e.g. upload a corrected master), click Replace File on the asset — the old file is archived (not deleted) and the new one becomes the active version.

Filtering & Search

Use the filter bar above the grid to filter by:

  • Type (Audio / Image / Video / Document)
  • Artist
  • Release
  • Version tag
  • Upload date range
  • Territory

The search box searches across title, tags, notes and linked artist/release names.

Promo Links from the Library

Right-click any asset → Create Promo Link to generate a time-limited streaming/download link. See the Marketing page for full promo link settings.

💡 Naming convention tip: Use a consistent naming scheme like ARTISTNAME_TRACKTITLE_VERSION_DATE.wav (e.g. DJVOID_ACIDRAIN_CLUBMASTER_20260301.wav). This makes sorting, exporting and sending files to distributors much less error-prone.
