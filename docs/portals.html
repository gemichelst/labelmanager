👤 Artist & Manager Portals

Portals give your artists and their managers a focused, role-appropriate view of the data relevant to them — without cluttering the screen with label-internal information they shouldn't see.

Artist Portal

When a user with the Artist role logs in, they land directly in the Artist Portal. The portal is personalised to the artist record linked to their account.

Portal Tabs

TabWhat artists see
OverviewStats card (releases, demos, balance due, confirmed gigs), latest releases, upcoming events
My ReleasesAll releases, type, status, release date, catalogue number, royalty share per release
My DemosAll submitted demos, genre, submission date, A&R status, rating (star display only)
FinancialsGross royalties, their split %, total received, current balance due; royalty history table; statement list with download
AssetsMedia Library assets marked as "Approved for Artist Portal" — with audio player for approved masters
ℹ️ Privacy: Artists cannot see other artists' data, the full CRM, Finance settings, or the A&R pipeline beyond their own demos. Internal notes tagged as "private" are never shown in portals.

Setting Up an Artist Account

1
Ensure the artist has a profile in Artists & CRM
2
Go to Settings → Users → + New User

Set role to Artist, then use the Linked Artist dropdown to connect the user account to the artist profile.

3
Share login credentials with the artist

Recommend they bookmark the app URL. On mobile it can be added to the home screen as a PWA.

Statements in the Portal

Approved royalty statements appear in the Financials → Statements section of the portal. Artists can view the HTML version inline or click Download PDF to get a formatted PDF copy.

Statements are only visible to the artist after a Label Manager or Admin clicks Approve Statement in the Royalties module — they are never shown automatically before review.

Manager Portal

The Manager Portal is a read-only view available to any user — it's accessed via the sidebar, not a separate login. It's designed to be shared with an artist's manager or booking agency during a screen share or handover call.

Manager Portal Tabs

TabContent
RosterAll Core Artist / Development artists: name, type, territory, genres, release count, confirmed gig count, contact button
Gigs & BookingsFull event list sorted by date: artist, venue, status, fee — read only
ReleasesAll releases with artist, type, date, status and task completion progress bar
PitchesDemos at Shortlist / In Talk / Offer / Signed stage — artist, genre, A&R status, rating stars
⚠️ Financial data: The Manager Portal does not show specific fee amounts, royalty splits or payout amounts by default. Fees are shown on the Gigs tab as they are operationally relevant for booking. To hide fees, disable the "Show Fees in Manager Portal" toggle in Settings → Portals.

Admin Portal Preview

Admins and Label Managers can preview any artist's portal view by going to Artist Detail → ⋯ → Preview Artist Portal. This is useful for verifying what an artist will see before granting them access.
