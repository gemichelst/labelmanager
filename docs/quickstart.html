⚡ Quick Start

Get LabelManager OS running and set up for your label in under 5 minutes.

Step 1 — Open the App

1
Clone or download the repository 
git clone https://github.com/yourusername/labelmanager-os.git
cd labelmanager-os
2
Open index.html directly — or serve locally

For basic use, just double-click index.html. For audio playback and file uploads to work correctly, serve it via a local server:

# Python (recommended)
python3 -m http.server 8080

# Node.js
npx serve .

# VS Code → Install "Live Server" → right-click index.html → Open with Live Server

Then open http://localhost:8080 in your browser.

3
Log in with the default admin account
EmailPasswordRole
admin@labelmanager.appadmin1234Admin
ar@labelmanager.appar1234A&R
artist@labelmanager.appartist1234Artist
⚠️ Change default passwords immediately if you plan to share the app with your team. Go to Settings → Users and update all default credentials.

Step 2 — Configure Your Label

1
Go to Settings → Label Profile

Set your label name, home country, default currency and primary accent colour. This information appears on statements, EPKs and export files.

2
Create your team accounts

Go to Settings → Users, click + New User and create accounts for each team member. Assign the correct role. See Roles & Permissions for a full breakdown.

3
Add your artists

Go to Artists & CRM, click + New Artist. At minimum fill in name, genres and status. You can add bios, social links and contracts later.

Step 3 — Load Your Data

If you're migrating from spreadsheets or another tool, there are two options:

Option A — Use the seed demo data

The app ships with demo artists, releases, demos and finance data so you can explore every module immediately. Go to Settings → Database to reset to empty when you're ready to go live.

Option B — Import existing demos

If you have a CSV export from LabelRadar, SubmitHub or Soundplate, go to Integrations → Platform Import and import directly into your A&R pipeline.
