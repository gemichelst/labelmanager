Select a Task Template

After setting the release date, choose a smart template. The system generates a backwards timeline of tasks automatically.

Smart Task Templates

Templates auto-generate a realistic task list backwards from your release date. Each task has a relative offset (e.g. "Artwork due: −21 days").

TemplateBest forTasks generated
Streaming SingleAlgorithm-focused digital single~14 tasks: pitch, pre-save, content plan, editorial submission
Club EPDance music, DJ-focused~18 tasks: DJ promo, Beatport setup, Juno, press kit

Release Timeline View

Each release has a Timeline tab showing all tasks plotted against the release date. Tasks are colour-coded by status:

  • To Do — Not started
  • In Progress — Being worked on
  • Review — Awaiting approval
  • Done ✓ — Completed
  • Overdue — Past due date, not complete

Drag tasks to reorder them. Click a task to set assignee, priority, due date and notes. If you change the release date, all task deadlines recalculate automatically.

Distributor Export

Once a release is ready for distribution, go to Integrations → Distributor Export, select the release and choose your distributor format. The system generates a complete delivery package with all track metadata, ready to upload. See the Integrations page for full details.

⚠️ ISRC reminder: Each track version needs its own ISRC. The Original Mix and Radio Edit of the same track are different ISRCs. Your distributor will assign ISRCs if you don't have your own IPI/ISRC registrant account.
