🔐 Roles & Permissions

LabelManager OS uses a role-based access control (RBAC) system. Each user is assigned one role that determines which modules they can access and what actions they can perform.

The Four Roles

👑 Admin

Full access to everything, including system settings, user management and database operations.

  • All modules — read & write
  • Create, edit, delete users
  • Reset or export the database
  • Configure integrations & webhooks
  • Access all artist portals
🏷️ Label Manager

Day-to-day label operations. Can do almost everything except critical system settings and user deletion.

  • CRM, A&R, Releases, Finance, Media, Events, Royalties
  • Marketing & Smart Links
  • Integrations (import/export)
  • Cannot delete users or reset DB
🎧 A&R

Focused on demo review, scouting and artist development. No access to finance or contracts.

  • Full A&R pipeline access
  • CRM — read only
  • Releases — read only
  • Media Library — upload & tag
  • No Finance, Royalties or Integrations
🎤 Artist

Artists only see their own data through the Artist Portal. They cannot access any other artist's information.

  • Artist Portal only
  • Own releases, demos, assets
  • Own royalty statements & payouts
  • No CRM, Finance settings, or A&R pipeline

Managing Users

1
Go to Settings → Users

All user accounts are listed here with their role, last login and linked artist (if applicable).

2
Click + New User and fill in the form

Required: name, email, password, role. For Artist role users, you must also link them to an artist record using the Linked Artist dropdown — this controls which artist's data they see in the portal.

3
Share credentials securely

Send the email and temporary password via a secure channel (Signal, 1Password share, etc.). Ask the user to change their password on first login in Settings → My Account.

⛔ Security note: LabelManager OS stores passwords as plain text in localStorage in the default (single-file) version. For production use with a real team, deploy the Node.js + PostgreSQL backend version which uses bcrypt hashing and JWT authentication.

Linked Artist Accounts

When you create a user with the Artist role, you must link it to an existing artist record. This link determines:

  • Which releases appear in their portal
  • Which demos they can see
  • Whose royalty statements and payouts are shown
  • Which media assets are marked as accessible to them

One artist record can have multiple user accounts (e.g. the artist + their manager both on artist-role accounts linked to the same artist).
