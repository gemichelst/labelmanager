📊 Royalties & Splits

The Royalties module handles the full cycle from CSV import of distributor statements, through split calculation, to artist-facing statements and payouts.

Royalty Contracts

Before importing royalties, set up a contract for each artist. Contracts define how income is split between the label and the artist (and any third parties).

Creating a Contract

1
Go to Royalties → Contracts → + New Contract
2
Configure the split
FieldNotes
ArtistLinked artist from roster
Contract TypeRecording, Licensing, Remix, Publishing, 360-Deal
Artist Split %Percentage of net royalties paid to artist
Label Split %Auto-calculated as 100% minus artist split

Importing Distributor Statements

Go to Royalties → Import. LabelManager OS supports CSV import from major distributors with pre-built column mapping profiles:

Import Workflow

1
Select your distributor from the dropdown
2
Drop your CSV file onto the import zone

A preview table shows the first 10 rows with the detected column mapping.

3
Review the mapping

For custom CSVs, use the column mapper to match your CSV headers to the LabelManager fields: Release ID/UPC, Track ISRC, Net Amount, Currency, Territory, Period, Revenue Source.

4
Click Import

The system matches rows to releases via UPC or ISRC. Unmatched rows are shown in a review table — you can manually match them or skip.

Split Calculation

After import, the split engine calculates each artist's share per royalty row based on their active contract. The calculation is:

Artist Share = Net Amount × (Artist Split % / 100)

If recoupable advance is outstanding:
  Artist Share is applied first to recoupment
  Payable to artist = max(0, Artist Share − Unrecouped Balance)

Statements

Statements aggregate royalty rows into a period report per artist. To generate:

  1. Go to Royalties → Statements → + Generate Statement
  2. Select artist and period (e.g. Q1 2026, H1 2026, Full Year 2025)
  3. Review the auto-generated statement showing gross royalties, label share, artist share, recoupment deductions and net payable amount
  4. Click Approve Statement — it becomes visible in the Artist Portal
  5. Optionally export as PDF or HTML for sending directly to the artist
💡 Statement schedule: Most labels issue statements quarterly (Q1–Q4) or bi-annually (H1/H2). Set up the statement generation reminder in Settings → Royalties → Statement Schedule — you'll get an in-app notification when the next period is due.
