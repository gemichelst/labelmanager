📈 Analytics

Analytics gives you a unified view of your label's performance — release metrics, A&R funnel health, channel effectiveness and team productivity — all in one place.

Overview Dashboard

The Analytics overview shows four key metrics blocks at the top:

  • Total Royalty Income YTD — year-to-date gross from all distributor imports
  • A&R Conversion Rate — percentage of demos that reach Signed
  • Releases Active — releases currently in production or campaign phase
  • Outstanding Payouts — total owed to artists

Release Performance

For each release, the Performance chart shows:

  • Monthly streaming/sales income over time (bar chart)
  • Cumulative income vs. production costs (line chart — shows break-even point)
  • Income by territory (pie chart)
  • Income by DSP/revenue source (bar chart)

Use the release dropdown to switch between releases. Set a date range to focus on a specific period.

A&R Funnel Analytics

The Funnel view shows conversion rates at each stage of the demo pipeline:

New → Reviewed:     [===========================] 85%
Reviewed → Shortlist:  [===============]          48%
Shortlist → In Talk:   [==========]               31%
In Talk → Offer:       [======]                   19%
Offer → Signed:        [====]                     12%
Overall (New → Signed):[=]                        2.4%

Hover over any stage bar to see the absolute number of demos at that stage and the average time spent there. Compare current quarter vs. previous quarter to track A&R efficiency improvements.

Channel Analytics

Track which promotional channels actually move the needle:

ChannelWhat's tracked
Promo LinksPlay count, download count, geography of recipients
Smart LinksClicks per DSP, pre-saves collected, geographic split
Demo Submission SourcesWhich URL/embed form demos came from
Contact OutreachHow many pitches sent to blogs/playlists, response rate (manual tracking)

Team Productivity

Admin and Label Manager roles can view team productivity stats:

  • Demos reviewed per A&R staff member this month
  • Average time-to-review (demo submitted → first status change)
  • Tasks completed on-time vs. overdue by team member
  • Release pipeline health — how many releases are on track vs. delayed
⚠️ Chart rendering: Analytics charts require Chart.js to be loaded. If charts appear blank, check that the Chart.js CDN script tag appears before your script.js in index.html. See FAQ for the full fix.
