🎧 Demos & A&R

The full artist-and-repertoire pipeline — from anonymous public submission to signed deal. A Kanban board, waveform player, star ratings and review workflow, all in one module.

The A&R Pipeline

Demos move through a 7-stage Kanban board. Each stage represents a real step in the decision-making process. Drag cards between columns or use the quick-select dropdown on each card.

New → Reviewed → Shortlist → In Talk → Offer → Signed ✓ · Rejected
StageMeaningTypical action
NewJust submitted, not yet heardListen and rate
ReviewedHeard and loggedAdd a comment, rate 1–5 stars
ShortlistStrong candidateShare with label head / A&R team
In TalkActive conversation with artistLink contact, log calls and emails
OfferContract terms discussedUpload contract draft to Media
Signed ✓Deal closedAuto-creates artist / links to existing
RejectedNot suitable at this timeOptionally send rejection email

Public Submission Form

Every label gets a shareable public URL at /submit (e.g. https://your-label.vercel.app/submit) that anyone can use to submit a demo — no login required.

File Upload Security

Files are uploaded directly to your S3 bucket with a random UUID filename — the original filename is never exposed publicly. Signed temporary URLs are generated for playback, expiring after 1 hour.

Waveform Player

Every demo with an uploaded audio file gets an interactive WaveSurfer.js waveform in its detail view. Features:

  • Play / pause with Space
  • Click anywhere on the waveform to seek
  • Waveform is pre-generated server-side for fast loading (no client-side decode delay)
  • Volume control and mute
  • Playback speed: 0.5×, 0.75×, 1×, 1.25×, 1.5×
  • Loop toggle

Star Ratings & Scoring

Each demo card shows a 1–5 star rating. Click any star to set the rating — this works directly from the Kanban board without opening the detail view. Ratings are per-user, and the card displays the average across all raters with a badge showing how many people have rated it.

The A&R Scoring Engine combines your manual rating with automated signals:

  • Genre match with existing roster artists (+weight)
  • BPM compatibility with label's typical range
  • Number of times played by team members
  • How fast it moved through the pipeline
  • External platform signals (if integration configured)

Comments & Review Workflow

The demo detail view has a threaded comment section below the waveform. Comments are timestamped, attributed to a user, and support @mentions. Use comments to:

  • Log your initial reaction after first listen
  • Discuss internally with the A&R team before moving to the next stage
  • Record negotiation notes (visible only to Admin / Label Manager)
  • Paste in email quotes from the artist

Search, Filter & Sort

Use the search bar above the Kanban to filter cards across all columns simultaneously. Additional filters:

FilterOptions
GenreFree text or select from existing genres in pipeline
RatingShow only demos rated 4+ or 5 stars
Date rangeSubmitted in last 7 / 30 / 90 days
SubmitterFilter by name or email
Linked artistOnly demos linked to a specific roster artist
SortDate submitted (default), rating, title, genre

Bulk Actions

Select multiple demo cards (checkbox top-left of each card) to apply bulk actions:

  • Move to stage — move all selected demos to a new pipeline column
  • Set rating — bulk-rate all selected
  • Export — export metadata (CSV) and optionally audio files (ZIP)
  • Delete — permanently delete (Admin only, requires confirmation)

Submission Notifications

Go to Settings → Notifications → Demos to configure who gets notified when a new demo is submitted. Options: in-app notification, email to A&R team, or Slack/Discord webhook message.
