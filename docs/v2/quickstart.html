Prerequisites

ToolVersionInstall
Node.js18 LTS or 20 LTShttps://nodejs.org
npm9+Bundled with Node.js
PostgreSQL14+https://postgresql.org or use Supabase
Gitanyhttps://git-scm.com

Installation

  1. Clone the repository 
    git clone https://github.com/yourusername/labelmanager-os.git
cd labelmanager-os
  2. Install backend dependencies 
    cd backend
npm install
  3. Install frontend dependencies 
    cd ../frontend
npm install

Database Setup

Option A — Supabase (recommended, free tier)

  1. Create a free project at supabase.com

    Note your project URL, anon key and database connection string from Settings → Database.

  2. Create a Storage bucket

    Go to Storage → New bucket, name it labelmanager-media. Set it to private.

  3. Run the schema migration 
    cd backend
node src/db/migrate.js

Option B — Local PostgreSQL

# Create database
createdb labelmanager

# Run migrations
cd backend
node src/db/migrate.js

Environment Variables

Copy the example file and fill in your values:

cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

Backend .env

# Database
DATABASE_URL=postgresql://user:password@host:5432/labelmanager

# Auth
JWT_SECRET=your-super-secret-jwt-key-min-32-chars
JWT_EXPIRES_IN=7d

# Storage (S3-compatible)
S3_ENDPOINT=https://your-project.supabase.co/storage/v1/s3
S3_ACCESS_KEY=your-access-key
S3_SECRET_KEY=your-secret-key
S3_BUCKET=labelmanager-media
S3_REGION=eu-central-1

# Server
PORT=4000
NODE_ENV=development
CORS_ORIGIN=http://localhost:5173

# Email (optional — for statement delivery)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=noreply@yourlabel.com
SMTP_PASS=your-app-password

Frontend .env

VITE_API_URL=http://localhost:4000/api
🔒
Never commit .env files

Your .env files contain secrets. The .gitignore already excludes them, but double-check before pushing to GitHub.

Seed & First Login

cd backend
node src/db/seed.js

This creates a set of demo artists, releases, demos and finance entries so you can explore every module immediately. It also creates the default users:

EmailPasswordRole
admin@labelmanager.appadmin1234Admin
manager@labelmanager.appmgr1234Label Manager
ar@labelmanager.appar1234A&R
artist@labelmanager.appartist1234Artist
⚠️
Change default passwords immediately

Go to Settings → Users and update all default credentials before sharing the app URL with your team.

Start both servers:

# Terminal 1 — Backend API
cd backend && npm run dev   # → http://localhost:4000

# Terminal 2 — Frontend
cd frontend && npm run dev  # → http://localhost:5173

Open http://localhost:5173 and log in with the admin credentials.

Configure Your Label

  1. Set your label profile

    Go to Settings → Label Profile. Enter your label name, home country, default currency and accent color. This information appears on statements, EPKs and distributor exports.

  2. Create team accounts

    Go to Settings → Users → + New User. Create accounts for each team member and assign the correct role. See Roles & Permissions for a full breakdown.

  3. Add your artists

    Go to Artists & CRM → + New Artist. At minimum fill in name, genres and status. Bios, social links and contracts can be added later.

  4. Reset demo data when ready to go live

    Go to Settings → Database → Reset to empty to wipe all seed data before importing your real label data.

Deploy to Production

Frontend → Vercel

cd frontend
npx vercel
# Set VITE_API_URL to your Railway/Render backend URL
vercel --prod

Backend → Railway

# Install Railway CLI
npm i -g @railway/cli

railway login
cd backend
railway init
railway add postgresql   # auto-injects DATABASE_URL
railway up

Set all remaining env vars in the Railway dashboard under Variables.

Full-stack → Docker Compose

docker-compose up -d
# Services: frontend (:80), backend (:4000), postgres (:5432)
