💿 Releases

Manage the complete lifecycle of every release — from concept and metadata through to live on DSPs — with integrated task timelines, campaign layers and distributor exports.

Release Lifecycle

Concept→ Production→ Mastering→ Promo→ Pre-Save→ Released

Creating a Release

Go to Releases → + New Release. Fill in the form:

FieldDescriptionRequired
TitleRelease title✅
Primary ArtistSelect from CRM roster✅
Featured ArtistsAdditional artist credits (comma separated)
TypeSingle, EP, Album, Compilation, Remix EP✅
Release DatePlanned or confirmed release date✅
LabelWhich imprint (if multi-imprint setup)
UPC/EANAuto-generated or enter manually
Genre / SubgenrePrimary and secondary DSP genre
P-Line / C-LineCopyright lines for metadata
LanguagePrimary language of the release
TerritoriesDistribution territories (worldwide or specific)
Internal NotesPrivate notes for the team

Track Management

Inside a release, go to the Tracks tab to add and manage individual tracks:

  • ISRC — auto-generated or manually entered
  • Track title, version name (Original Mix, Radio Edit, Instrumental, Dub)
  • Duration — auto-read from uploaded audio file
  • Composers, lyricists, producers — linked to CRM contacts or free-text
  • Publisher — publishing rights holder
  • BPM, Key — auto-detected or manual
  • Explicit flag
  • Linked audio file — from Media Library
  • Royalty splits — per track, linked to Royalties module contracts

Release Task Timeline

Each release has a built-in task timeline with default task templates. The timeline shows all tasks as a Gantt-style view relative to the release date.

Default task categories (fully customizable in Settings):

  • 📦 Production: Final mix delivery, master delivery, artwork delivery
  • 📋 Admin: ISRC registration, UPC registration, contract sign-off
  • 🚀 Distribution: Distributor upload, DSP delivery deadline, pre-save campaign live
  • 📣 Marketing: Press release, playlist pitching, social content schedule
  • 📊 Post-release: First-week report, 30-day report, playlist placement tracking

Metadata Validation

Before marking a release as "ready for distribution", the Metadata Validator checks:

  • All required DSP fields are present
  • ISRC format is valid for each track (CC-XXX-YY-NNNNN)
  • UPC/EAN format is valid (12 or 13 digits)
  • Artwork meets DSP specs (3000×3000px minimum, JPEG/PNG, <10 MB)
  • Audio files are 44.1kHz / 16-bit minimum (or 24-bit for Mastered for iTunes)
  • P-Line and C-Line are present
  • No duplicate ISRCs within the release

A green ✅ badge appears on the release card when all checks pass.

Distributor Export

When metadata validation passes, click Export → Distributor Package to generate:

  • CSV/TSV — compatible with most distributor ingest systems
  • XML (DDEX ERN 4.1) — for distributors requiring DDEX format
  • ZIP bundle — metadata file + audio files + artwork in one archive
💡
Distributor Profiles

Go to Settings → Distributors to configure export profiles for each distributor you use (DistroKid, FUGA, The Orchard, Redeye, etc.). The exporter will format the file to match each distributor's requirements automatically.
