📊 Royalties & Splits

The complete royalty engine: multi-contract management, distributor CSV import, automated split calculations, statement generation and artist payouts.

Contracts

Each artist can have one or more contracts. Go to Royalties → Contracts → + New Contract:

FieldDescription
ArtistLinked from CRM roster
TypeLabel Deal, Licensing, Remix, Publishing, Sync
Royalty RateArtist's percentage of net receipts (e.g. 50%)
AdvanceAmount advanced to artist (recoupable)
Recoup fromWhich releases count towards recoupment
TerritoryWorldwide or specific territories
TermContract start and end date
Minimum PayoutDon't pay out until balance reaches this threshold
Payment ScheduleMonthly, Quarterly, Bi-annual, Annual

Distributor CSV Import

Go to Royalties → Import → + New Import to import sales and streaming data from your distributor:

  1. Select your distributor profile

    Pre-built profiles: DistroKid, FUGA, The Orchard, Redeye, Believe, TuneCore, CD Baby, Bandcamp. Or create a custom mapping.

  2. Upload the CSV or TSV file

    The importer previews the first 10 rows and highlights any mapping issues.

  3. Confirm the mapping and import

    The system matches rows to tracks by ISRC, then to releases and artists. Unmatched rows are flagged for manual review.

  4. Review and confirm

    Check totals match your distributor statement, then confirm. The data is locked and feeds into statement generation.

Statement Generation

Go to Royalties → Statements → Generate. Select the artist(s), period and contract. The system:

  1. Sums all import data for the period matching the artist's releases
  2. Applies the royalty rate from the contract
  3. Deducts any unrecouped advance balance
  4. Applies minimum payout threshold check
  5. Generates a PDF/HTML statement with itemised breakdown

Statements can be delivered via email directly from the app (SMTP config required) or downloaded as PDF to share manually.

Per-Track Splits

For tracks with multiple contributors, go to the Track detail view in a Release and click + Add Split. Define splits as percentages (must sum to 100%). Each split holder must be a CRM contact or user. The split engine applies these splits when calculating individual contributor payouts from the total track earnings.
