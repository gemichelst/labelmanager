What is LabelManager OS?

LabelManager OS is a single-file progressive web app that runs entirely in your browser. No backend required, no installation, no monthly fees. All your label data is stored locally using browser localStorage — portable and fully under your control.

It replaces the fragmented label workflow of Notion + Google Sheets + Dropbox + email chains with one coherent, dark-mode system designed for the way modern independent labels actually work.

Core Concepts

Single Source of Truth

Every piece of data — artists, releases, demos, contracts, events, royalties, media assets — lives in a single relational JSON structure. Nothing is duplicated. Change an artist name once and it updates everywhere: releases, demos, statements, portals.

Workflow-First Design

Everything is organized around pipelines and timelines, not just lists. The Demo Kanban, Release Timeline, Booking Pipeline and Royalty Statement flow are designed to match how you actually work, not how a database admin thinks you should.

Roles & Portals

Different people on your label see different things. A&R staff work in the demo pipeline. Artists see their own releases, financials and assets. Managers get a read-only overview. Admins see everything. Nobody sees what they shouldn't.

Pro tip

For the best experience, bookmark the app and use it in a dedicated browser profile for your label. This keeps your data separate from personal browsing and prevents accidental localStorage clears.

CDN Dependencies

LabelManager OS relies on three libraries loaded from CDN. They must be included in index.html before your script.js:

<!-- In <head>, BEFORE script.js -->
<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.3/dist/chart.umd.min.js"></script>
<script src="https://unpkg.com/lucide@latest/dist/umd/lucide.min.js"></script>
<script src="https://unpkg.com/wavesurfer.js@7/dist/wavesurfer.min.js"></script>
⚠️
Load order is critical

If Chart.js loads after script.js, you will see Chart is not defined errors. Always verify the order in your HTML <head>.

Data Storage & Export

All data is stored in localStorage under the key labelmanager_db. To back up or migrate your data, use Settings → Database → Export JSON or run this in the browser console:

const data = localStorage.getItem('labelmanager_db');
const blob = new Blob([data], { type: 'application/json' });
const a = document.createElement('a');
a.href = URL.createObjectURL(blob);
a.download = 'labelmanager-backup-' + new Date().toISOString().split('T')[0] + '.json';
a.click();
