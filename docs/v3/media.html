📁 Core Modules

Media Library

Your central asset hub — every audio file, artwork, press photo and video, tagged, searchable and playable.

📖 7 min read 🕐 Last updated May 2026

The Media Library is your central asset hub — every audio file, artwork, press photo, logo, social asset and video in one place, fully tagged, searchable and playable.

Uploading Files

Two ways to upload:

  • Drag & drop — drag files directly onto the Media Library grid
  • Click to browse — click the upload area to open a file picker

Supported formats: MP3, WAV, AIFF, FLAC, M4A, OGG, AAC, MP4, MOV, JPG, PNG, GIF, WebP, SVG, PDF

Maximum file size: 50 MB per file (for audio). Larger files should be stored externally (Google Drive, Dropbox, S3) and linked by URL.

Waveform Player

Every audio file in the library has an inline waveform player. Features:

  • Scrubbing — click anywhere on the waveform to jump to that position
  • Markers — add named markers for Intro, Drop, Break, Outro for quick navigation during review
  • Loop — set loop points for A/B comparison of sections
  • Speed — playback at 0.5×, 1×, 1.5×, 2×

Promo Links

Create time-limited, optionally password-protected streaming and download links for DJs, blogs and radios:

1

Select an asset → ⋯ → Create Promo Link

2

Set expiry date and optional password

Expired links show a polite "this preview has expired" page.

3

Copy link and share

Each link is unique and trackable — see how many times it was played or downloaded in Analytics → Channel Analytics → Promo Links.

Search & Filter

  • Full-text search across file names, tags and notes
  • Filter by type, artist, release, territory, portal-approved status
  • Sort by name, date added, size, artist
  • Toggle between grid view (thumbnails) and list view
ℹ️
External storage

In the current version, audio files uploaded via the Media Library are stored as base64 data URLs in localStorage. For production use with large catalogues, link assets by URL from external storage (S3, Google Drive, Dropbox) rather than uploading the binary.
