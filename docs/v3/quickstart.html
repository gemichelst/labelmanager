⚡ Getting Started

Quick Start

Get LabelManager OS running and set up for your label in under 5 minutes.

📖 6 min read 🕐 Last updated May 2026
1

Open the App

Clone or download the repository and open index.html. For audio playback and file uploads to work correctly, serve it via a local server:

# Python (recommended)
python3 -m http.server 8080

# Node.js
npx serve .

# VS Code → Install "Live Server" → right-click index.html → Open with Live Server

Then open http://localhost:8080 in your browser.

2

Log in with the default admin account

EmailPasswordRole
admin@labelmanager.appadmin1234Admin
ar@labelmanager.appar1234A&R
artist@labelmanager.appartist1234Artist
⚠️
Change default passwords immediately

Go to Settings → Users and update all credentials before sharing with your team.

3

Configure Your Label

Go to Settings → Label Profile and set your label name, home country, default currency and primary accent colour. This information appears on statements, EPKs and export files.

4

Create Team Accounts

Go to Settings → Users, click + New User and create accounts for each team member. Assign the correct role. See Roles & Permissions for a full breakdown of what each role can access.

5

Add Your Artists

Go to Artists & CRM, click + New Artist. At minimum fill in name, genres and status. You can add bios, social links and contracts later.

6

Load Your Data

The app ships with demo data so you can explore every module immediately. Go to Settings → Database → Reset to Empty when you're ready to go live.

If you have a CSV export from LabelRadar, SubmitHub or Soundplate, go to Integrations → Platform Import to import directly into your A&R pipeline.
