Releases

Manage the full release lifecycle — from idea to post-campaign — with automatic task timelines and campaign layers.

📖 9 min read 🕐 Last updated May 2026

The Releases module manages the complete lifecycle of every release — from initial idea through to post-campaign — with automatic task timelines and campaign layers.

Release Lifecycle

Every release moves through a defined status chain:

Idea → A&R Selected → In Production → Mastered → Distributor Setup
     → Pre-Save → Scheduled → Released → Post-Campaign

💡
Shifting the release date

If you move a release date, all tasks linked to that release are automatically recalculated. Open the release, click the date field and pick a new date — the task timeline rebuilds instantly.

Release Timeline View

The timeline shows all tasks for a release arranged by due date relative to the release date. Each task has:

  • Name — what needs to happen
  • Assigned to — team member responsible
  • Due date — auto-calculated from template offset
  • Status — Todo, In Progress, Done, Blocked
  • Notes — optional detail or link

Campaign Layer

The Campaign Layer adds marketing events on top of the task timeline:

  • Social posts — scheduled content pieces
  • Playlist pitches — blog/playlist outreach entries
  • Ad flights — paid campaign periods with budget
  • Press releases — PR outreach deadlines

All campaign events are relative to the release date, so they shift automatically if the date changes.

Tracks & Metadata

Each release can have one or more tracks. In the Tracks tab of the release detail view, add each track with:

  • Title, version (Radio Edit, Extended, Instrumental, Club Mix)
  • ISRC code, duration, BPM, key
  • Credits: producers, writers, performers, mixers, masterers
  • Publisher, P-Line, C-Line, explicit flag, language

Release Assets

In the Assets tab, link media library files to the release:

  • Artwork (3000×3000px minimum for DSPs)
  • Audio masters (streaming master, club master, vinyl master)
  • Press photos
  • Social assets (square, story, banner)
